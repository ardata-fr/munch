# Chunks Theme Element for 'ggplot2'

A theme element that renders 'flextable' chunks directly in plot titles,
subtitles, captions, and other text positions. This allows using
superscripts, subscripts, and other formatting not available in
markdown.

## Usage

``` r
element_chunks(
  chunks,
  hjust = NULL,
  vjust = NULL,
  angle = NULL,
  lineheight = NULL,
  size = NULL,
  margin = NULL,
  debug = FALSE,
  inherit.blank = FALSE,
  width = NULL
)
```

## Arguments

- chunks:

  A paragraph object created with
  [`flextable::as_paragraph()`](https://davidgohel.github.io/flextable/reference/as_paragraph.html)
  containing chunks such as
  [`flextable::as_chunk()`](https://davidgohel.github.io/flextable/reference/as_chunk.html),
  [`flextable::as_sup()`](https://davidgohel.github.io/flextable/reference/as_sup.html),
  [`flextable::as_sub()`](https://davidgohel.github.io/flextable/reference/as_sub.html),
  etc.

- hjust:

  Horizontal justification (0-1).

- vjust:

  Vertical justification (0-1).

- angle:

  Text rotation angle in degrees.

- lineheight:

  Line height multiplier.

- size:

  font size

- margin:

  Margins around the text (use
  [`ggplot2::margin()`](https://ggplot2.tidyverse.org/reference/element.html)).

- debug:

  Show debug rectangles.

- inherit.blank:

  Should this element inherit blank elements.

- width:

  Maximum width of the text in inches, for titles, subtitles and
  captions, which wrap to their available width by default. With
  'patchwork' or a fixed aspect ratio, the available width is not known
  when the height of the title is computed: the text may need more lines
  than the space kept for it, and setting `width` solves this. It is
  ignored for rotated text and for text with an explicit position.

## Value

An element of class `c("element_chunks", "element_text", "element")`.

library(ggplot2)
library(flextable)
library(ggiraph)

library(gdtools)
font_set_liberation()

#>   mono:    Liberation Mono [liberation]
#>   symbol:  Liberation Sans [liberation]

  font.size = 12,
  font.family = "Liberation Sans"
)

# Caption with subscript (H2O)
p <- ggplot(mtcars, aes(mpg, wt)) +
  geom_point() +
  theme_minimal(base_family = "Liberation Sans") +
  theme(
    plot.caption = element_chunks(
      as_paragraph(
        as_chunk("Chemical formula: "),
        as_chunk("H"),
        as_sub("2"),
        as_chunk("O")
      )
    )
  )

x <- girafe(
  ggobj = p,
  options = list(opts_sizing(rescale = FALSE)),
  dependencies = list(
    liberationsansHtmlDependency()
  )
)
