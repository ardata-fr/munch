# Plot a mdGrob

Draws an mdGrob object to the current graphics device.

## Usage

``` r
# S3 method for class 'mdGrob'
plot(x, ...)
```

## Arguments

- x:

  A mdGrob object.

- ...:

  Additional arguments (ignored).

## Value

A grid grob object of class "mdGrob" representing rich text content
(invisibly).
